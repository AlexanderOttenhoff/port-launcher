# Android patches for Banjo: Recompiled's libraries

Applied on top of the submodule commits BanjoRecomp pins (rt64 6f1c2d9, plume d890ac8,
N64ModernRuntime ca568b6). They are the JFG Android changes (github.com/AlexanderOttenhoff forks
of rt64, plume and N64ModernRuntime, `jfg-android` branches), cherry-picked; the rt64 patches that
only moved the plume submodule pointer were resolved to the patched plume.

Long term these belong upstream (RT64, plume, N64ModernRuntime), as for JFG.
